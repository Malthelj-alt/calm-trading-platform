# Data

`sample_btcusdt_1h.csv` holds **sample data, not real market prices**: exactly 920 hourly bars from a seeded random walk around 60,000, starting 2024-01-01T00:00Z. It is deterministic, so you can run and test offline. You can rebuild it byte-for-byte with `python3 scripts/fetch_binance.py --make-sample`. Its sidecar `sample_btcusdt_1h.meta.json` labels the source `sample (not real market)`. `btcusdt_1h.csv` is the real data. It is created by `python3 scripts/fetch_binance.py`, which pulls the last 920 closed BTCUSDT 1h bars from Binance's public klines endpoint. That endpoint needs no key, and the script falls back to data-api.binance.vision. `btcusdt_1h.meta.json` records the source URL, the fetch timestamp and the source label `binance-public`. Both CSVs have the same header: `open_time_ms,open,high,low,close,volume` (UTC milliseconds, oldest first, prices as decimal strings). If the network is unavailable, the fetch script exits non-zero and writes nothing.
